## 📊 FORMULA LOGIC OVERVIEW

### Revenue Calculation
```
Annual Revenue = Volume × Price × (1 + Escalation Rate)^(Year-1) × 1000
```
- Fresh-pack: Assumptions B17 (volume) × B20 (price) × escalation
- Frozen: Assumptions B24 × B27 × escalation
- Seeds: Assumptions B31 × B32 × escalation
- Feed: Waste generation × conversion rate × B37 (price) × escalation

### Operating Costs Calculation
```
Raw Materials = Throughput × Farmgate Price × (1 + Escalation)^(Year-1)
Labor = Sum of 7 departments × 12 months × (1 + Escalation)^(Year-1)
Utilities = (Grid + Generator + Water + Diesel) × (1 + Escalation)^(Year-1)
Consumables = (Oil + Packaging + Additives + Cleaning + Maintenance + QC) × Escalation
Depots = 4 depots × (Staff + Electricity + Rent + Maintenance) × 12 months
```

### CAPEX Calculation
```
Total CAPEX = Phase 1 (Year 0) + Phase 2 (Year 2) + Phase 3 (Year 3)
Each Phase = Sum of line items × (1 + Contingency %)
```

### P&L Calculation
```
Revenue - Cost of Sales = Gross Profit
Gross Profit - Operating Expenses = EBITDA
EBITDA - Depreciation = EBIT
EBIT - Interest = EBT
EBT - Tax = Net Income
```

### Cash Flow Calculation
```
Operating CF = Net Income + Depreciation - Working Capital Changes
Investing CF = -CAPEX
Financing CF = Equity + Debt Drawdown - Debt Repayment
Net CF = Operating CF + Investing CF + Financing CF
```

### Returns Calculation
```
Project IRR = IRR(Net Cash Flows Years 0-10)
NPV = NPV(Discount Rate, Cash Flows Years 1-10) + Year 0 Cash Flow
DSCR = EBITDA / Debt Service
```
